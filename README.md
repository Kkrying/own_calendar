# AI 학회 일정 캘린더

AI/ML 주요 학회(NeurIPS, MICCAI, CVPR, ICML, ICLR, ECCV, ICCV, AAAI, WACV)의 마감일·발표일·학회 일정을 iCalendar(`conferences.ics`) 피드로 제공합니다. 매월 둘째·넷째 월요일에 자동 갱신됩니다.

구독 URL: `https://raw.githubusercontent.com/Kkrying/own_calendar/main/conferences.ics`

## Outlook 구독 방법
- **Outlook 웹 / 새 Outlook**: 캘린더 > 캘린더 추가 > 웹에서 구독 에 위 URL을 붙여넣기
- **클래식 Outlook**: 캘린더 추가 > 인터넷에서

## 참고
- 모든 날짜는 각 학회 공식 웹사이트에서 확인한 값이며, 공식 발표되지 않은 일정은 포함하지 않습니다. 예측·추정 값은 사용하지 않습니다.
- 시각이 명시되지 않은 마감일은 23:59 AoE(UTC-12)로 간주했습니다.
- Outlook의 구독 캘린더 갱신에는 몇 시간이 걸릴 수 있습니다.
- 공식 페이지 간 불일치로 제외한 항목: AAAI-27 반박 기간(두 범위가 겹쳐 표기됨), ICLR 2027·CVPR 2027 개최 도시(미확정).
